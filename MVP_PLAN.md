# DebateLab MVP Plan

Цель: превратить текущий кликабельный демо-прототип в минимально рабочее приложение, которым можно дать пользоваться другим людям.

## Текущий статус

- UI уже опубликован/готов к публикации на Vercel.
- Навигация, страницы, видео-секция и браузерный голосовой ввод частично работают.
- Профиль, друзья, статистика, чемпионаты, рейтинги и результаты судейства сейчас демо/статические данные.
- Базы данных для продукта пока нет: `db/schema.ts` пустой.
- Auth helper есть в `app/chatgpt-auth.ts`, но страницы его пока не используют.
- Кнопки `Start bot debate`, `Start friend debate` и `Enter` пока не запускают реальные сценарии.

## Порядок работ

1. Определить MVP
   - Первый реальный сценарий: пользователь заходит, логинится, дебатит с ботом, получает AI-оценку, видит результат в профиле.
   - Не пытаться сразу делать друзей, чемпионаты и real-time.
   - Для первой версии ограничить сценарий:
     - 3-5 заранее заданных motion.
     - выбор стороны: `for` или `against`.
     - короткий формат: 1-3 пользовательских аргумента и ответы бота.
     - судейство после завершения раунда.

2. Подключить логин
   - Использовать существующий helper `app/chatgpt-auth.ts`.
   - Защитить личные страницы от анонимных пользователей.
   - Заменить захардкоженный профиль `Ilya K.` на текущего пользователя.
   - При первом входе создавать пользователя в базе или обновлять его данные.

3. Сделать базу данных
   - Минимальные таблицы:
     - `users`
     - `debates`
     - `debate_turns`
     - `scores`
   - Позже добавить:
     - `friendships`
     - `championships`
     - `championship_entries`
     - `rankings`

4. Сделать backend/API слой для MVP
   - Добавить server actions или API handlers:
     - `getOrCreateUser`
     - `createDebate`
     - `addDebateTurn`
     - `generateBotReply`
     - `judgeDebate`
     - `getProfileStats`
   - UI не должен напрямую собирать бизнес-логику дебата.
   - Ошибки AI, базы и auth должны возвращаться в понятном для UI виде.

5. Сделать реальный `Debate with bot`
   - `Start bot debate` должен создавать дебат.
   - Пользователь выбирает motion/side.
   - Аргументы пользователя сохраняются.
   - Бот отвечает через реальный AI вызов, а не через статический текст.
   - История раунда должна восстанавливаться из базы после перезагрузки страницы.

6. Сделать реальное AI-судейство
   - `Judge and rank me` должен отправлять debate history в AI-судью.
   - Возвращать структурированную оценку:
     - structure
     - logic
     - evidence
     - rebuttal
     - speaking/style
     - overall score
     - rank
     - feedback
   - Сохранять score в базе.
   - Формат ответа AI должен быть JSON, чтобы профиль и история не зависели от свободного текста.
   - Если AI вернул невалидный JSON, показать ошибку и не сохранять частичный score.

7. Сделать профиль и историю
   - Главная страница должна показывать реальные данные пользователя.
   - Показать:
     - количество дебатов
     - score history
     - average score
     - последний debate
     - текущий rank
     - последний feedback
   - Wins/losses оставить на этап friend/championship mode.

8. Почистить UX
   - Добавить loading states.
   - Добавить error states.
   - Добавить empty states.
   - Сделать кнопки честными: если функция не работает, не показывать ее как рабочую.
   - Проверить мобильную версию.

9. Потом сделать друзей
   - Первая версия: debate по invite-ссылке.
   - Оба пользователя добавляют аргументы.
   - AI судит раунд.
   - Real-time оставить на потом.

10. Потом сделать чемпионаты
   - Делать только после пользователей, результатов и рейтинга.
   - Нужны правила:
     - кто может войти
     - как создаются пары
     - как начисляются очки
     - как выбирается победитель

11. Финальная проверка Vercel
    - Проверить production build.
    - Проверить env vars.
    - Проверить auth.
    - Проверить базу.
    - Проверить голосовой ввод на HTTPS.
    - Проверить телефон.
    - Проверить ошибки в browser console.

## Самый важный следующий шаг

Начать с пунктов 2-3 вместе: подключить логин, добавить минимальную базу и сделать `getOrCreateUser`.

После этого сделать пункт 4: backend/API слой для одного сценария.

После этого сделать один полноценный сценарий: `Debate with bot` + AI judging + сохранение результата.
